# Cricket Score App

A simple cricket scoring web app for local matches.

## Features

- Create a match with two teams and overs
- Record runs, wides, no-balls, byes, leg-byes, and wickets
- Automatic batting and bowling scorecards
- Overs, run rate, target, and required runs
- Save match progress in the browser
- Mobile-friendly design

## How to Use

1. Open the website.
2. Enter both team names and total overs.
3. Click **Start Match**.
4. Select the current batter and bowler.
5. Tap the scoring buttons after every ball.
6. Click **End Innings** after the first innings.
7. Continue scoring the second innings.

## Data Storage

Match data is saved in your browser using localStorage.
Clearing browser data may delete the saved match.
